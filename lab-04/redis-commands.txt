Кеш виручки за березень 2026 року.
Запускати з кореня проєкту:
docker compose -f compose-nosql.yaml exec redis redis-cli
Команди вводити по одній. У звіт занести власні відповіді.

1. Записати суму:
SET revenue:2026-03 1540.00
Відповідь: OK

2. Прочитати:
GET revenue:2026-03
Відповідь: "1540.00" — текст, не число.

3. Перевірити TTL:
TTL revenue:2026-03
Відповідь: -1 — ключ без строку дії.

4. Задати 30 секунд:
EXPIRE revenue:2026-03 30
Відповідь: 1 — строку встановлено.

5. Перевірити залишок:
TTL revenue:2026-03
Відповідь: приблизно 30 секунд.

6. Перевірити ключ:
EXISTS revenue:2026-03
Відповідь: 1 — ключ є.

Почекати 30 секунд.

7. Перевірити після спливу:
GET revenue:2026-03
Відповідь: (nil) — ключ видалено.

8. Перевірити TTL:
TTL revenue:2026-03
Відповідь: -2 — ключа немає.

9. Записати кеш на 5 хвилин:
SET revenue:2026-03 1540.00 EX 300
Відповідь: OK

10. Збільшити лічильник:
INCR reservations:2026-03-12:count
Відповідь: 1, якщо ключ створено вперше.

Кеш-aside:
1. GET revenue:2026-03 — якщо (nil), це промах.
2. Окремо в PostgreSQL виконати запит суми оплат:
SELECT sum(payment.amount)
FROM reservations AS reservation
JOIN payments AS payment USING (reservation_id)
WHERE reservation.starts_at >= TIMESTAMPTZ '2026-03-01 00:00:00+02'
  AND reservation.starts_at <  TIMESTAMPTZ '2026-04-01 00:00:00+02';
3. Результат 1540.00 записати: SET revenue:2026-03 1540.00 EX 300
4. Наступний GET читає кеш: "1540.00".
